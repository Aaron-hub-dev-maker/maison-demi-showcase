# Maison Demi

*Luxury, by half.*

**Live demo: [maison-demi.onrender.com](https://maison-demi.onrender.com/)**

Maison Demi is an off-price marketplace for premium and luxury Indian houses. Each house
sells its previous-season pieces under its own name, at least 40% below the original price.
It starts with shirts, kurtas, dresses, denim and t-shirts, and is growing towards
everything an outfit needs, footwear included, always from houses worth buying.

> **This is a demo.** The houses, pieces and photos are samples, payments are simulated
> (nothing is charged), and the phone code at checkout is shown on screen instead of being
> texted. Please don't expect a parcel. The first visit can take up to a minute while the
> free server wakes up.

---

## How it works

- **A marketplace, not a shop.** Houses keep their own stock, list it here, and ship each
  order themselves. Maison Demi never holds inventory; it earns a commission on each sale.
- **Brand-safe.** Discounted pieces appear only here, never next to full-price collections.
- **Made for broken stock.** End-of-season stock means many styles with few units left in
  odd sizes, so stock is tracked size by size and shoppers can filter for their own size.
- **Every piece is checked.** A house's application is approved by hand, and each new piece
  is verified before it goes on sale.

## What you can do on the demo

**As a shopper**
- Browse by category or by house, search, and filter by size, price and discount.
- Save pieces, follow houses, and get an email when a size comes back or a price drops.
- Check out: one parcel per house, a phone code to confirm the number, and an emailed
  invoice. Then track the order, cancel it, or request a return.
- Works on any screen, from a 320-pixel phone up.

**As a house** (apply from *Sell on Maison Demi* in the footer)
- Apply, then list pieces one at a time or many at once from a spreadsheet, with photos
  straight from your own shoot.
- Ship orders with tracking, handle returns, and see earnings and payouts.
- Invite your team.

## Built with

| Part | Technology |
|---|---|
| Storefront | React, TypeScript, Tailwind CSS |
| Server | Python, FastAPI, SQLAlchemy |
| Database and photos | PostgreSQL and Storage on Supabase |
| Email | Brevo |
| Hosting | Render |

Security features include two-step sign-in for admins, rate limits, a robot check on sign-up,
row-level security on every database table, and strict content-security rules in the browser.
